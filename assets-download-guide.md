# Инструкция: Какие файлы скопировать с Tilda сайта

## Что нужно скачать с https://www.mastershake.kz/

### 1. Логотип/Фавикон
**Где искать:**
- Осмотри исходный код страницы (Ctrl+U)
- Ищи теги `<link rel="icon">` или `<link rel="apple-touch-icon">`
- Обычно Tilda использует: `/tilda-favicons/` или `/img/`

**Файлы для скачивания:**
```
favicon.ico (16x16, 32x32)
apple-touch-icon.png (180x180)
og-image.jpg (1200x630 для соцсетей)
```

**Куда сохранить:**
```
public/favicon.ico
public/apple-touch-icon.png
public/og-image.jpg (или создать новый)
```

---

### 2. Изображения/Иконки на странице

**На текущем сайте практически НЕТ изображений**, только:
- Логотип Tilda внизу (не нужен)

**Что нужно СОЗДАТЬ:**

#### A) Плейсхолдеры для мастеров
Создай или найди подходящие изображения:
```
public/images/master-1.jpg  (Шурабатыр)
public/images/master-2.jpg  (Андрей)
public/images/master-3.jpg  (Яша)
```

**Рекомендации:**
- Размер: 400x400px (квадрат)
- Формат: WebP (для оптимизации) или JPG
- Можно использовать:
  - Фото мастеров (если есть)
  - Плейсхолдеры с https://ui-avatars.com/
  - Иконки профессий

#### B) Логотип "Мастер+Шаке"
```
public/images/logo.png
public/images/logo-white.png (для темного фона)
```

**Как создать:**
- Простой текстовый логотип
- Или использовать Figma/Canva
- Размер: 200x60px (прозрачный фон)

#### C) Иконки (не обязательно - можно использовать lucide-react)
Вместо скачивания используй React иконки:
```typescript
import { Phone, MapPin, Clock, Wrench } from 'lucide-react'
```

---

### 3. Шрифты

**Tilda использует системные шрифты**, поэтому:
- В Next.js используй Google Fonts (Inter или Roboto)
- Уже настроено в `next/font/google`

**НЕ нужно ничего скачивать**

---

### 4. Цветовая схема

**Извлеки из исходного кода Tilda:**

Открой инспектор (F12) и посмотри:
```css
/* Основные цвета на сайте */
background: #ffffff
text: обычно #000000 или темно-серый
accent: синий/зеленый для кнопок

/* Рекомендую использовать: */
primary: #2563eb (синий Tailwind)
secondary: #10b981 (зеленый для WhatsApp/CTA)
```

## Быстрая инструкция по скачиванию

### Способ 1: Через браузер (если есть изображения)
```bash
# 1. Открой https://www.mastershake.kz/
# 2. Правый клик на изображении → "Сохранить изображение как..."
# 3. Или открой DevTools (F12) → Network → Img → скачай файлы
```

### Способ 2: Скрипт для скачивания (если много файлов)
```bash
# Если на сайте будут изображения
wget -r -l1 -H -t1 -nd -N -np -A.jpg,.png,.svg,.ico \
  -erobots=off https://www.mastershake.kz/
```

### Способ 3: Инспектор кода
```bash
# 1. Ctrl+U (исходный код)
# 2. Ctrl+F найди: 
#    - "favicon"
#    - ".png"
#    - ".jpg"
#    - ".svg"
# 3. Скопируй URL и скачай через wget или curl
```

## Рекомендация

**Для быстрого старта:**
1. Используй lucide-react иконки вместо изображений
2. Создай минималистичный текстовый логотип
3. Для мастеров используй цветные аватары с инициалами
4. Фавикон сгенерируй через https://favicon.io/

**Так ты можешь запустить сайт БЕЗ ожидания реальных фото!**

После запуска можно постепенно заменить плейсхолдеры на реальные изображения.
