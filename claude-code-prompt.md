## Этап 1: Инициализация проекта

Создай новый Next.js проект с TypeScript:

```bash
npx create-next-app@latest mastershake-website
```

Настройки при установке:
- TypeScript: Yes
- ESLint: Yes
- Tailwind CSS: Yes
- `src/` directory: Yes
- App Router: Yes
- Import alias (@/*): Yes

**После выполнения - ОСТАНОВИСЬ и жди подтверждения**

## Этап 5: Настройка Tailwind и globals.css

Обнови `src/app/globals.css` с базовыми стилями:

```css
@tailwind base;
@tailwind components;
@tailwind utilities;

@layer base {
  html {
    scroll-behavior: smooth;
  }
  
  body {
    @apply bg-white text-gray-900 antialiased;
  }
}

@layer components {
  .btn-primary {
    @apply bg-blue-600 hover:bg-blue-700 text-white font-semibold px-6 py-3 rounded-lg transition-colors duration-200;
  }
  
  .btn-secondary {
    @apply bg-green-500 hover:bg-green-600 text-white font-semibold px-6 py-3 rounded-lg transition-colors duration-200;
  }
}
```
